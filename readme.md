# 🧮 Python Calculator

A simple command-line calculator built using Python. This project allows users to perform basic arithmetic operations through a menu-driven interface.

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Menu-driven interface
- 🔢 Supports integer and decimal numbers
- 🚪 Exit option

---

## 🛠️ Technologies Used

- Python 3

---


## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Python-Calculator.git
```

2. Open the project folder

```bash
cd Python-Calculator
```

3. Run the program

```bash
python main.py
```
